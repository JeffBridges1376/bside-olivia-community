# Changelog

每个版本的完整内容、升级方式和已知问题见 [`docs/releases/`](docs/releases/) 下对应的更新说明；附件以 [GitHub Releases](https://github.com/Ornn8/bside-olivia-community/releases) 为准。

## 2.0.1 - 2026-09-29

修复 2.0.0 发布后反馈的问题。详见 [2.0.1 更新说明](docs/releases/v2.0.1.md)。

- 从 1.x 升级、曾用自填接口写回信的用户，启动时自动用已有的 Olivia 账户 Key 连接回信服务，不再寄信失败。
- 回信服务未连上 Key 时，寄信前直接提示去“连接并保存”。
- 寄信前的回信形式判断与正式回信同一标准：“给我看看”算图片，明确要视频才算视频。
- 随信照片光线与回信一致，姿态自然，上课场景有老师和同学。
- 消费账单写明每次最低 ¥0.01 的计费规则。

## 2.0.0 - 2026-09-29

汇总自 1.3.14 以来的改动。详见 [2.0.0 更新说明](docs/releases/v2.0.0.md)。

- **JEV 判断链路**：回复意图、媒体形式、人格信息选择、记忆检索与核验、世界更新、情绪、主动联系和回复复核统一由云端 JEV 判断；判断异常明确记录，不悄悄回退到旧的小模型。
- **世界与聊天、信件联动**：回复后单独判断是否需要更新世界，区分打算、进行中、已完成和取消；回复使用对应时刻的世界证据。
- **生活事件与用餐**：世界事件补充过程、结果、角色感受与后续打算；三餐分别记录状态和时间，今日安排按时间排列课程与用餐。
- **情绪、关系与角色变化**：持续情绪综合交流、世界经历、身体状态和作息；兴趣与偏好变化需要经历支持。
- **记忆一致性**：保留原话、说话人、时间和来源，处理后续更正与跨轮指代。
- **信件、QQ 与启动体验**：随信照片藏在信纸下露出一角，语音工具栏移到信纸外；QQ 图片发送确认独立等待 120 秒；新开机动画播完停在末帧，等主界面就绪再退出。
- **只需一个 Olivia 账户 Key**：移除 DeepSeek、OpenCode Go、阿里云百炼等自填大模型接口和自填 GPU 服务地址，升级后旧配置被忽略。
- 实时对话（Live）暂不提供，以后再做。
