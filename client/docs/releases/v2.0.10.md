# Olivia 2.0.10

本次恢复林离在合适时候主动附带照片，修复回复里念出聊天记录格式和重复上一句的问题，并让启动画面不再挡住其他窗口。

## 照片

- 从 2.0.0 起，只要你没有明确要照片，林离几乎不会再随回信或聊天附上照片。
- 现在开启图片后，你没有特别要求媒体时，她会按回信内容判断：回信里有她此刻能被拍下的画面（在哪、在做什么、穿着、吃的、看到的景色），或者你在想念、关心她的近况时，会顺手附一张；寒暄、道别、讲解知识、严肃的倾诉、争执道歉，或你说过不想收照片时不附。
- 照片类型会按内容选择：想看她本人时是自拍或镜前照，食物、风景、小动物时是景物照。
- 你明确要语音或照片时仍按要求发送，不会再额外叠加一张照片。开启图片的信会在这个判断完成后再显示为送达。

## 回复更稳定

- 修复林离偶尔把 `[历史消息 {…}]` 这类聊天记录格式当成回复说出来。
- 一条回复和最近几条已发送的回复一字不差时，会重新生成，不再重复上一句。
- 回忆旧事时，如果暂存记忆关联这一步出错，不再让整轮回复忘掉所有旧记忆；诊断包会记录回忆失败的具体环节，便于继续排查“想不起约定过的事”。

## QQ 默认用语音

- QQ 普通聊天现在默认用语音回复；只有她确实不方便开口，或需要原样给出代码、链接、公式时才发文字。语音合成失败时仍会发出文字。
- 以后才要的照片、歌曲不再让这一轮的聊天只能发文字；你这一轮明确要求的媒体和“别发额外媒体”的要求照常遵守。

## 导入灵离备份

- 设置里的“选择文件导入”支持灵离的 `.soul` 备份，只导入文字，跳过已有的相同原文，不覆盖现有信件。

## 启动

- 启动画面不再始终置顶，启动较慢时可以随时切换到其他窗口；按 Esc 仍可跳过。
- 绑定 QQ 时，QQ 组件改为在后台启动，不再拖住程序就绪。
- 诊断包会记录启动各阶段的耗时，便于进一步定位启动慢的原因。

## 升级方式

在 **设置 → 更新与帮助 → 选择补丁并更新** 选择本页附件中的补丁包，完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置都会保留。
