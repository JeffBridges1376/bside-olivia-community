# Olivia 2.0.7

本次修复 QQ 聊天中部分回复发送失败、显示 `PERSONAL_CHAT_DECISION_INVALID` 的问题。

## QQ 回复

- 林离在 QQ 回复时，可能顺带安排一次之后的主动联系（例如“明天找你”），或根据你的话调整聊天偏好（例如暂停主动联系）。此前只要这类附带设置不合规，整条回复都会作废：比如在深夜把联系时间约在早上 8:30 之前的免打扰时段、偏好变化找不到你的原话依据、时间超过七天。
- 现在只忽略不合规的那一项设置，回复正文照常发送。免打扰时段、需要你原话依据、主动联系时不改变你的偏好等保护规则不变。被忽略的设置会记录在诊断中，便于排查。

## 更新方式

已有用户下载 `Olivia-2.0.7.zip` 或 `Olivia-2.0.7.oliviapatch`，在“本地陪伴 → 补丁更新”中导入，完成后完全退出并重新打开 Olivia。更新保留 Olivia 账户 Key、信件、记忆和设置。

## 已知问题

- 如果林离在回复里口头答应了某个时间联系你，但这个时间落在免打扰时段，这次联系不会被安排；她不会在夜间主动找你。
- 信箱中没有日期的导入旧信仍显示为 1970-01-01（按本机时区显示时间）。这是原版界面对“无日期”的显示方式，不影响回忆。
- 关闭窗口时默认仍是“最小化到托盘后台运行”。如需关闭后彻底退出，请在关闭提示中选择“直接退出应用”并勾选“记住该设定”。
