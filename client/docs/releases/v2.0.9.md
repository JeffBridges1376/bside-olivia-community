# Olivia 2.0.9

本次让林离在 QQ 日常聊天里更常用短语音回复。

## QQ 语音

- 此前，只要你没有明确要语音，林离在 QQ 上几乎总是回文字。
- 现在，你没有要求图片或语音时，林离会按聊天内容自己决定用语音还是文字：问候、闲聊、安慰、撒娇、晚安等适合开口说的一两句话多用短语音；讲解、步骤、地址、数字等需要你反复查看的内容仍用文字。
- 你明确要语音或照片时仍按要求发送。照片只在你要求或确实需要时发送，不会主动增加。
- 语音发送失败时会自动改发文字。

## QQ 上下文调整

- QQ 回复时，最近的聊天记录与固定规则放在一起，按固定步长滚动，连续几轮可以直接复用，回复更稳定。

## 升级方式

在应用内检查更新即可，或下载本页附件中的补丁包覆盖安装。聊天记录、记忆和设置都会保留。
