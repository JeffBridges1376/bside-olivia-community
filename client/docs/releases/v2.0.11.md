# Olivia 2.0.11

本次修复 2.0.10 开启图片后普通信件一直显示"林离回信中…"的问题，QQ 重启后不用再重新扫码，并减少林离用挖苦的语气回应你真心话的情况。

## 信件

- 修复 2.0.10 的问题：开启图片后，没有特别要求媒体的信，回信已经写好却一直停在"林离回信中…"，始终不送达。升级后重新打开 Olivia，之前卡住的信会继续处理并送达。
- 照片的计划改由服务器完成，林离判断是否附照片、拍什么的方式以后可以直接在服务器上调整，不必再等客户端更新。

## QQ

- 登录过的 QQ 账号会被记住，Olivia 或 QQ 组件重启后会自动快速登录，不再需要重新扫码绑定。若 QQ 本身的登录已失效（例如在其他设备登录被顶下线），仍需重新扫码。

## 语气

- 林离仍然可以不同意、拒绝、嘴硬、调侃或简短冷淡，但不会再拿你真诚表达的委屈、想念或请求来挖苦，也不会把她自己说过的话当成你的说法来反驳。这类回复会先被改写再发出。

## 诊断

- 诊断包总会带上最近的几封信，不再被长期卡住的旧聊天记录挤掉，便于排查"收不到信"。

## 升级方式

在 **设置 → 更新与帮助 → 选择补丁并更新** 选择本页附件中的补丁包，完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置都会保留。
