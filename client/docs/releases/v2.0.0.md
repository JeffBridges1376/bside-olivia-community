# Olivia 2.0.0

本次说明汇总自上一发布版 1.3.14 以来的新增功能与修复。

## 世界与生活

- 重整世界页面，将今天的安排、牵挂与关系、生活记录分开呈现，显示当前活动、地点、更新时间与状态依据。
- 课程、用餐和实际生活活动按时间顺序排列；区分课表计划与已发生记录，连续相同活动合并展示，减少重复的“休息”条目。
- 补充角色的学期、课程与上海当地时间、天气信息；当前课程和下一节课随时间变化，初始学期计划不会无限沿用。
- 增加用餐过程记录，区分未到时间、尚未确认、未吃、正在吃、已经吃完，并记录已知的用餐时间和食物。没有证据时不会直接把“没记录”当成“没吃”。
- 回信和聊天中产生新的生活事实后，单独判断是否需要更新世界；已吃完、改变去向、开始或结束活动等信息可进入同一份生活记录。
- 世界事件补充发生过程、遇到的问题、应对方式和结果，让日常经历能够影响后续状态与回复。
- 在空闲时段结合当前生活、课程、精力和未完成事项选择后续活动；休息加入恢复判断，减少长时间只重复同一状态的问题。
- 为短期活动和事项增加时间边界与进度更新，过时的“明早有课”等事项不再长期占据“最近在忙”；长期练习、创作和共同约定仍可持续保留。
- 修复世界页面直接显示 JSON、内部字段或含糊判断说明的问题，“挂心的事”改为描述具体事件。

## 情绪、人格与关系

- 增加持续的情绪状态、变化原因与来源记录，综合用户交流、世界事件、身体感受和作息影响，而不只根据用户一句话变化。
- 区分当前情绪、变化记录和未知状态；缺少有效记录时不再默认展示为“平静”。
- 人格资料按当前话题选择相关部分，阶段性学习与生活安排进入世界计划；新增经历对兴趣、偏好和性格表现的持续影响记录。
- 加强关系事项、共同约定与后续进展的时间顺序和来源关联，减少旧记录覆盖较新状态、事项重复出现的问题。
- 信件、QQ、主动联系以及语音、图片、歌曲等回复共享本轮选定的人格和世界依据，减少不同渠道各说各话。

## JEV 判断与记忆

- 将回复意图、媒体选择、相关信息选择、世界更新、情绪、记忆提取和回复检查等语义判断接入 JEV；主回复模型负责表达。
- 按模块合并可同时完成的判断，使用结构化输出，缩小输入到本次原文、必要提示和少量相关信息，减少重复判断与无关历史输入。
- 媒体预检只判断当前来信需要的回复形式，不再提前执行完整回复计划，修复部分普通信件和语音请求无法寄出的问题。
- 发布版默认连接经过账号认证的云端 JEV 服务，无需手动配置开发机判断服务；显式开发配置仍可保留。
- 改善相关历史选择、原文回查和事实归属；旧说法与后续更正保持关联，避免只找回旧结论而漏掉纠正。
- 保留已接收用户原文和来源关系，改善未回复输入、跨话题回忆以及记忆写入中断后的恢复；未发送的回复草稿不会当作已经说过的话。
- 增加按需联网检索判断，只在当前问题确有需要且服务支持时使用检索。
- 附带记忆迁移工具与使用说明，便于处理既有记忆资料。

## QQ 与主动联系

- 改善 QQ 号码保存、绑定状态反馈和首次绑定后的监听启动，设置页刷新不再频繁打断正在填写的内容。
- 连接测试、接收消息与生成回复分开处理；生成耗时较长时仍可接收并保存新消息，减少队列堵塞后一直不回复的问题。
- 新消息可在发送前更新本轮回复依据，避免连续追问后仍发送只回答旧消息的草稿；尚未开始处理的消息可在重启后恢复。
- 改善连接异常、回复失败和发送结果不确定的提示与恢复。发送结果尚未确认时，不会盲目重复发送或提前写成成功记录。
- 改善 QQ 语音、图片与世界状态的衔接，修复照片后来已送达但先显示失败提示等状态不同步问题。
- 主动联系结合关系、近期交流、生活事件和可分享事项判断时机；尊重暂停联系、待回复、冷却与未回应限制，减少重复触发。
- 未读主动信件可在后续正常聊天中轻量提醒，并避免跨渠道反复提醒。

## 语音、图片、视频与歌曲

- 统一文字和媒体回复的本轮依据，改善媒体需求识别、媒体计划复用及失败恢复。
- 改善语音配置、语音任务与其他媒体工作的衔接，保留文字与媒体各自的完成状态，避免把部分完成误报为全部成功。
- 图片回复结合当前请求和已选定的世界信息，改善任务恢复、照片记忆及送达确认。
- 演唱、翻唱与原创歌曲接入本轮人格和世界依据，改善内容计划和已有结果复用。
- 调整信件语音工具栏、波形样式、音量控制及添加到曲库的入口，工具栏放在信纸外，减少遮挡正文。

## 信件与界面

- 调整信纸尺寸和照片层级：照片收起时藏在信纸下方并露出一角，展开、收起与查看大图之间增加动画衔接。
- 改善寄信失败、重新寄信和媒体预检的状态反馈，保留可重试内容，减少长时间卡在等待回信的情况。
- 修复内部判断结果、原始 JSON 和技术说明进入用户可见正文或世界描述的问题。
- 更新 Community 开机动画与配乐，以较小的独立窗口展示；视频播完后停留在最后一帧，直到主程序准备好。
- 修复旧启动画面未替换、残留空白窗口和启动画面覆盖曲库等问题，更新包会将动画安装到实际启用的版本目录。
- 扩充诊断中的判断、回复和媒体故障信息，便于区分连接、生成、发送与世界写入问题，同时避免在诊断中记录密钥和私人正文。

## 更新方式

已有用户下载 `Olivia-2.0.0.zip` 或 `Olivia-2.0.0.oliviapatch`，在“本地陪伴 → 补丁更新”中导入，完成后完全退出并重新打开 Olivia。更新保留已有账号配置、信件、记忆和设置，无需重新导入记忆包。

智能判断及云端媒体功能需要可用的云服务与有效账号。服务不可用时会显示相应状态；尚未确认的事件或未完成的生成不会被当作已成功完成。
