# Olivia 2.0.3

本次修复记忆回忆失效导致林离“编造往事”的问题，并降低每封回信的判断成本。

## 回忆与编造

- 修复回忆几乎总是失败的问题。此前只要候选的往来记录里有一条空白消息（例如只发了表情或图片），或某段原文过长、句子过多，整次回忆就会放弃，林离手里没有可核对的原话，于是会记错是谁说的、编出不存在的细节。现在这类记录只是不参与引用，回忆照常进行；原文太多时按相关度少取一些。
- 回忆不可用时，会明确要求林离如实说记不太清或请你提醒，不得指认是谁说的、谁答应的，也不得编造时间、地点、物品等细节。

## 寄信更稳定、成本更低

- 回信后的质量检查改为“先检查、有问题再确认”：大多数回信只需一次检查，检查规模不再随回信长短增长。发现问题时才会追加一次确认（账单中显示为“JEV判断：回信质量确认”）。
- 世界状态筛选改为“必需 / 有帮助 / 不需要”三档判断，同等内容下判断成本约降低两成；候选过多时少取一些，不再导致回信失败。

## 诊断

- 信件和回忆失败时，诊断包会记录失败步骤和原因代号（不含信件内容），便于排查。

## 更新方式

已有用户下载 `Olivia-2.0.3.zip` 或 `Olivia-2.0.3.oliviapatch`，在“本地陪伴 → 补丁更新”中导入，完成后完全退出并重新打开 Olivia。更新保留 Olivia 账户 Key、信件、记忆和设置，无需重新导入记忆包。

## 已知问题

- 关闭窗口时默认仍是“最小化到托盘后台运行”。如需关闭后彻底退出，请在关闭提示中选择“直接退出应用”并勾选“记住该设定”。
